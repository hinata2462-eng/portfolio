シルバーアクセサリー店の自社ECサイト構築

楽天で売っているシルバーアクセサリーの店が、初めて自社のECサイトをShopifyで開くための一式を作りました。楽天店と同じ見た目のテーマ、商品データの一括作成、商品画像の加工、他社サイトの分析、作業の手順書です。

ShopifyLiquidPythonOpenCVClaude Code
見本：商品名・価格・画像の名前はすべて架空です

困りごと

楽天の手数料は実質9〜15%かかります。自社のECサイトを持てば、決済の手数料は3%台に下がります。ただ、商品は楽天・Yahoo!ショッピング・Amazonにそれぞれ出ていて、商品名も画像も少しずつ違います。長さ違い・色違いまで手で入れると間違いが出ますし、楽天の表紙画像には楽天向けの文字やバッジが入っていて、そのままでは使えません。担当の方はエンジニアではないので、作業の手順も具体的に書く必要がありました。

仕組み

  1. 楽天店の見た目を写し取るトップページと商品ページの並び（看板・ランキング・カテゴリ・商品情報の表）を細かく調べ、Shopifyのセクション（Liquid）にしました。最初は11個に分かれていた貼り付け用の部品も、1つにまとめ直しています。
  2. 商品データを一度に作る各モールの商品ページから、商品名・価格・長さや色の違い・説明画像を集め、Shopifyにそのまま取り込める表（CSV）をスクリプトで作ります。直しが入るたびに全商品を作り直し、11版まで改良しました。
  3. 表紙画像を整えるOpenCVで、表紙画像に入った文字やバッジを消して背景を埋め直します。消した画像はShopifyに置き、テーマから参照します。
  4. 売れている自社ECを調べる海外と日本のブランド16社の自社ECサイトを、同じ8つの観点で見比べたレポートを作りました。
  5. 手順書を渡す「どの画面を開き、どこを押し、何を貼るか」まで書いた手順書です。作業は3つにまとめ、それぞれ3〜5分ほどで終わるようにしました。

工夫したこと

  • 商品名・価格・画像を「どのモールのものを正とするか」を版ごとに決め、毎回スクリプトで全商品を作り直しました。手で直さないので、取り込み直しても食い違いが出ません。
  • 長さや色を選ぶと、表紙と説明画像もその長さのものに切り替わるようにしました。
  • 文字消しでは、赤いバッジを色で自動で見つけますが、探すのは画像の下の部分だけにしています。全体を探すと、人の肌の色をバッジと間違えて消してしまうためです。
  • 楽天のクーポンやキャンペーン、LINEへの誘導の画像は、自社ECの説明画像から外すルールにしました。楽天のレビュー表示も外し、自社ECで新しく集める形に切り替えています。
  • 手順書は「どの画面を開いて、どこを押して、何を貼るか」の細かさで書き、作業の数そのものも減らしました。

結果

32商品・48通りの長さ・色違いを、Shopifyに取り込める商品データにしました（11版）。表紙画像は9枚の文字消しと、48枚をShopifyに置く形への切り替えまでを行い、楽天の画像への参照は0件になりました。31商品の名前をAmazonの正式名にそろえ、テーマの部品は11個から1つにまとめています。決済や表示義務のページなど、公開前に必要な設定はチェックリストにまとめて渡しました。
