AIの仕組みづくり・調査 · 2026.11

作ったものの棚卸しスキル

AIと一緒に作ってきた物を、会話の履歴や作業フォルダから遡って洗い出し、1つの道具を1行にまとめた一覧を作るスキルです。このポートフォリオの元になっています。

Claude Code スキルPython
見本：架空の道具で作った、出力の一部です

困りごと

4か月ほどでAIと作った物がどんどん増え、何をいつ作ったのか、自分でも思い出せなくなりました。人に見せる資料を作ろうとすると、取引先の名前や個人の情報が混ざってしまう心配もあります。

仕組み

  1. 下調べを自動で集めるPythonのスクリプトが1〜2分で、下の6か所から材料を集めて1つのファイルにします。前回からの差分だけを集めることもできます。
  2. 材料を最後まで読んでから書く材料は長いので、分けて全部読みます。途中で書き始めると、後ろの方の物が抜けるからです。
  3. 1つの道具を1行にまとめる同じ物の版違いや、関係するメモが20件あっても1行に。中身が分からない物は説明ファイルを読んで確かめ、それでも分からなければ「要確認」と書きます。
  4. カテゴリ別に書き出す業務の効率化／Web・EC制作／アプリ／AIの自動運用・発信／AIの仕組みづくり、の順。前回の一覧があれば、増えた物を先頭に置きます。
  5. 返事は短く合計の件数、カテゴリごとの件数、ファイルの場所、載せなかった物とその理由だけを伝えます。

読む所

01AIのメモ

AIが覚えている、案件ごとのまとめ。

02会話の履歴

会話ごとの最初の依頼文と日付。決まった時間に動く回は、回数だけ数えます。

03作業フォルダ

デスクトップや作業フォルダの中身と、説明ファイルの冒頭。起動用のショートカットも。

04予定タスク

毎朝・毎夕など、決まった時間に自動で動く仕組み。

05スキル

自分で作った、AI向けの手順書。

06公開ページ

公開した作品の題名と、更新した日。

1行の書き方

- 名前（始めた年月〜）｜状態 — 困りごと → できること（1〜2文）。数字があれば1つ。／使ったAI・技術／場所
  • 状態は「使用中・公開中・運用中・完成・試作・デモ・準備中・停止」のどれか。
  • 数字は記録にある物だけ。盛らない。うまくいかなかった数字も、書くなら正直に。
  • 作ったAIを分ける（Claude製・Codex製・ChatGPT製）。
  • 調べ物や相談だけの会話、好みのメモ、他人の設計書を読んだだけの物は載せず、「載せなかったもの」に理由と一緒に残す。

人に渡す資料に使う時の決まり

  • 社名や取引先の名前は、業種に置き換える。自分の物・もう公開している物は実名でよい。
  • パスワード、お客の名前、見積の金額、社内の件数は書かない。
  • URLは、誰でも開ける公開中の物だけ。自分しか開けないページは載せない。
  • 代表作は5〜8件を「困りごと → 作った物 → 結果（数字）」で書き、残りは一覧にする。

工夫したこと

  • 材料集めはスクリプトに任せ、まとめる所だけAIが考える形に分けました。集める所で抜けが出ると、後で気づけないからです。
  • 決まった時間に何十回も動く仕組みは、会話1回ずつではなく、タスクの名前ごとに回数だけを数えます。一覧が同じ物で埋まらないようにするためです。
  • 「自分用」と「人に渡す用」で決まりを分けました。同じ一覧から、職務経歴やポートフォリオを安全に作れます。
